# GIS source intake / การนำเข้าข้อมูล GIS

Do not place downloaded data here without a source manifest. Every dataset must record provider, license, attribution, source URL, acquisition date, CRS, horizontal/vertical accuracy notes, and missing-geometry notes.

ห้ามนำข้อมูลมาใส่โดยไม่มี source manifest ทุกชุดต้องระบุผู้ให้บริการ ใบอนุญาต ข้อความ attribution URL วันที่ได้ข้อมูล CRS ความแม่นยำแนวราบ/แนวดิ่ง และข้อจำกัด geometry ที่หายไป

Expected layers: roads, rivers/water, building footprints, land use, elevation/DEM, and spawn points. This repository intentionally contains no geographic data and no invented Ayutthaya coordinates.
